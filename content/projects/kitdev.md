KitDev Space is a growing suite of developer utilities that run in the browser or on the server without persisting any data. Tools are grouped into labs: data (JSON formatting, JSON to TypeScript, converters between JSON, YAML, TOML, XML and JSON5, text diff), crypto (hashing, Base64 and hex encoding, UUIDs, random strings, password hash benchmarking), color (conversion, contrast checking, palettes, inspection), network (DNS lookup, HTTP headers, URL and redirect inspection, OpenGraph preview), image (conversion to WebP, AVIF, JPEG or PNG, resizing, metadata stripping, orientation), and dev (semver, cron, tar archives, TypeScript and JSX transpiling).

KitDev Space is open source. New labs and tools are added regularly.
